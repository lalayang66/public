# 老張小館 線上點餐系統

## 檔案說明
- `index.html` — 顧客點餐頁面(掃桌上QR code或分享網址就能開啟)
- `kitchen.html` — 店家後台(訂單看板 + 菜單管理,建議自己收藏這個網址,不要給顧客)

這兩個檔案已經接好你的 Supabase 資料庫,不用額外設定就能直接使用。

## 第一次使用前
菜單目前是空的,請先打開 `kitchen.html` → 點「菜單管理」→ 用上面的表單新增幾樣菜色。

## 部署到網路上(讓顧客真的能用手機打開)
照 Claude 對話裡教的步驟:
1. 把這兩個檔案上傳到 GitHub 的一個新 repository
2. 用 Vercel 匯入這個 repository,不用設定任何 Build command(這是純靜態網頁)
3. 部署完成後會得到兩個網址,例如:
   - `你的專案.vercel.app` → 給顧客用(顧客點餐頁)
   - `你的專案.vercel.app/kitchen.html` → 給店家自己用(後台)

## 安全性小提醒
程式碼裡的 Supabase 金鑰是 `anon public` 這組,設計上就是給前端網頁公開使用的,不是機密金鑰,可以放心讓它出現在程式碼裡。
